SetWidget3DVisibleUnattached( self, widget, isVisible )

Меняет видимость Widget3D для указанного контрола (должен быть в текущем Control3DSafe) при отсутствии привязки к объекту.

Примечание: Видимость Widget3D определяется стандартной видимостью виджета и, либо видимостью объекта привязки, либо данным флагом.

Примечание: При создании нового Widget3D (через AddWidget3D) данный флаг выставляется в false.

-- класс
Control3DSafe

-- семантика
function SetWidget3DVisibleUnattached( self, widget, isVisible )

-- входные параметры:
widget: WidgetSafe - 2D-контрол, для которого меняется видимость Widget3D
isVisible: boolean - отображать ли Widget3D при отсутствии привязки к какому-либо объекту

-- возвращаемое значение:
нет

-- пример
wtControl3D:SetWidget3DVisibleUnattached( widget, true )
