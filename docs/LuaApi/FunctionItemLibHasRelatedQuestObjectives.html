itemLib.HasRelatedQuestObjectives( itemId )

Проверяет наличие целей заданий игрока, которые связаны с указанным предметом.

-- библиотека:
itemLib

-- объявление:
function HasRelatedQuestObjectives( itemId )

-- параметры:
itemId: ObjectId (not nil) -- идентификатор предмета
object: три варианта
 nil - проверить наличие связанных целей заданий в целом
 QuestId - связь с конкретным заданием
 ObjectId (QuestObjective) - связь с конкретной целью задания

-- возвращаемые значения:
boolean - true, если такие цели задании имеются у игрока.

-- пример:
local hasQuestObjectives = itemLib.HasRelatedQuestObjectives( itemId )
