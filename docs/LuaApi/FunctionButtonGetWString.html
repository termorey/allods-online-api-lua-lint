ButtonSafe:GetWString( self )

Получить отображаемую строку из текста текущего варианта кнопки. Все невидимые элементы (теги, стиль и тп) будут утрачены.

Если требуется получить форматную строку, то надлежит использовать сочетание ButtonSafe:GetValuedText() + userMods.FromValuedText( text )
