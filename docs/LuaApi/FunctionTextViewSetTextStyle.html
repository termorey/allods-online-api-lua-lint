SetTextStyle( self, styleTable )

Изменяет стиль текста. Описание стиля смотреть в WidgetTextStyle.

Можно передать частичную таблицу стиля. Поля не заданные в таблице будут оставлены без изменений.

Примечание: Механиески работает как оверрайд поля textStyle из ресурса виджета.

Примечание: Изменение приводит к полному пересозданию RenderValuedText, не рекомендуется использовать без крайней необходимости.

-- класс
TextViewSafe

-- семантика
function SetTextStyle( self, styleTable )

-- входные параметры
styleTable: table - таблица описывающая стиль

-- возвращаемое значение отсутствует

-- пример
wtTextView:SetTextStyle{ multiline = true, lineSpacing = 1.5 }
